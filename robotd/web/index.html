RoboDev

How RoboDev works

Auto mode asks before: flashing firmware, motors, installing packages, system or boot files, deleting things, rewriting git history, files in data/ and public posts. Everything else (reading, editing code, commands, restarts) just runs. Every change is a git commit, and a restart that breaks robotd rolls back by itself. Anyone near the robot can talk to it, so voice requests are limited to the mode chosen above. Secrets (API keys, passwords) are never shown to the model. You can also reach RoboDev from Claude Code or other agents through the robot's MCP server (robot_dev_send).
